# Sponsor

L1nSn0w's sponsor hub — a postage-stamp thank-you wall plus a "buy me a coffee"
CTA, at [sponsor.sn0w.fyi](https://sponsor.sn0w.fyi). Built with React,
TypeScript, Vite, and Tailwind CSS v4.

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build   # → dist/
```

Edit the thank-you wall and support link in `src/sponsors.json`.
